mixing.edit¶

Render a re-edit of a finished video from a sound edit list and its picture clips.

Re-editing a finished talking-head video with an editor’s eye means two edit lists of the same length: the sound (which source spans play, and where a silence is inserted) and the picture over it (the source, punched in or not, or a held still with a slow move, dissolving or cutting between clips). render() takes both and renders the film, frame-exact:

>>> from mixing.edit import Span, Gap, Cam, Still, render
>>> render(
...     [Span(0.0, 4.2, "a"), Span(5.0, 9.0, "b"), Gap(1.5, "card"), Span(9.0, 12.0, "a")],
...     {"a": Cam(), "b": Cam(zoom=1.3, cx=0.4), "card": Still("card.png", dissolve_in=0.5)},
...     source="talk.mp4",
... )

Sound. Each segment is a Span of source seconds or a Gap of silence. Spans snap to source frames. Consecutive spans that are contiguous in the source play as one unbroken run; every other join gets a short fade (JOIN_FADE_S) so it does not click.

Picture. Each segment names a clip id. Consecutive segments with the same id form one picture clip, so a Still keeps its move across a sound cut (that is how a pause is removed invisibly) and a Cam punch-in hides a jump cut. Under a Cam clip:

  • a span shows its own source frames;

  • a Gap holds the frame next to it: the last frame of the previous span of the same clip, or, when the gap opens the clip, the first frame of the next span. (A Cam clip made only of gaps has nothing to show and is refused.)

Frame-exact by construction. The timeline runs at the source rate as a Fraction (30000/1001 stays exact; fps= overrides). Output frame boundaries are cumulative integer frame counts and each sound boundary is round(frame * sample_rate / fps) of the same frame boundary (one rounding per boundary, never accumulated), so sound and picture never drift and end on the same instant. timeline() is that arithmetic, pure and testable without ffmpeg; render() executes it.

Dissolves. dissolve_in=D on a clip renders it D/2 early and the outgoing clip D/2 late (a Cam clip shows the source frames beyond its span, a Still runs its move longer), joined with ffmpeg xfade, so the total length is unchanged.

Picture and sound fades. closing_fade= fades the last frames to black and the sound to silence over the same frames (the last frame is black and silent).

Overlays. Each Overlay is an image with alpha shown over a time range (optionally fading), composited in the final pass, which also applies an optional closing fade and muxes the sound. An overlay starting at or after the film’s end is refused; one running past it is clipped to it, its fades shortened to fit. A tituli label is one way to make the image (tituli.render(lower_third(...), frame) returns a PIL image, which an Overlay accepts); nothing here depends on tituli.

Stills go through a strategy slot, still_renderer, defaulting to burns_still_renderer(): the move is resolved by burns.resolve_move (named moves such as "push_in", or an explicit path), a still of another aspect is pillar- or letterboxed rather than silently cropped, and windows stay inside the still’s content box. burns comes from the media extra and is imported only when a still is rendered.

Bounded memory. The picture is rendered as parts: one small ffmpeg run per source piece (seek, resample, trim, punch-in) or still slice, one two-input run per dissolve, each written as a lossless intermediate in a temporary directory, then read back to back by the concat demuxer in the final pass. No run opens more than two decoders, however many segments the edit has. The sound is assembled in memory from one PCM decode of the source (32-bit float: about 115 MB for five minutes of 48 kHz stereo).

What is assumed of the source.

  • It has a video and a sound stream (the first of each is used) and an even width and height (the delivery is yuv420p); others are refused.

  • Source seconds count from the first video frame. A sound stream that starts later or earlier (its start_time) is shifted back into sync.

  • Frame-exact identity assumes a constant frame rate. A variable-rate source (r_frame_rate and avg_frame_rate disagree) is resampled by time to its nominal rate, each frame the nearest source frame, with a warning; fps= resamples the same way.

  • A display rotation is applied by ffmpeg on decode; the size used is the displayed one.

  • The source’s length is its counted video packets (ffprobe) or, without ffprobe or for a variable-rate source, its duration; a span past it is refused. Without ffprobe the rate is read from ffmpeg’s banner (snapped by as_rate()) and both streams are taken to start together.

  • The PCM sound is handled as little-endian float (every platform ffmpeg ships for in practice).

Everything runs through ffmpeg subprocesses (mixing.util.ffmpeg_exe()); importing this module pulls no media library.

class mixing.edit.Still(image, path='hold', zoom=None, fit='fit', content_box=None, on_aspect_mismatch='raise', dissolve_in=0.0)[source]¶

Bases: object

A held still image with a slow move.

image is a path or a PIL image. path is the move, resolved by burns.resolve_move: a name from burns.MOVES ("hold", the default, "push_in", "drift_left", …), a burns.BurnsPath, or its to_dict() payload. zoom is a named move’s end zoom (None: HOLD_ZOOM for a hold, burns’ default otherwise).

fit decides what happens when the image’s aspect is not the frame’s: "fit" (default) letter- or pillarboxes it, so the whole picture is held and never silently cover-cropped; "fill" lets burns crop it to cover the frame. content_box (normalized (x, y, w, h) of the image) is the part that is picture, e.g. inside a pillarboxed card: every window of the move is slid inside it (centred on it where the window is larger), so a zoomed move never shows the bars. Bars added by fit="fit" are outside the content box automatically. A transparent still is flattened onto PAD_COLOR, its alpha honoured. on_aspect_mismatch is passed to burns.resolve_move for an explicit path authored at another aspect ("raise", default, or "refit").

The move spans the whole picture clip, whatever sound cuts happen under it.

mixing.edit.as_rate(value)[source]¶

A frame rate as an exact Fraction.

Strings are parsed exactly; a float near an integer or an NTSC rate (k * 1000 / 1001) is taken to mean it.

>>> as_rate("30000/1001"), as_rate(29.97), as_rate(25), as_rate(23.976)
(Fraction(30000, 1001), Fraction(30000, 1001), Fraction(25, 1), Fraction(24000, 1001))

mixing.edit.burns_still_renderer(still, *, frames, fps, size, output)[source]¶

Render still as exactly frames frames of size with burns.

The move is resolved by burns.resolve_move at the frame’s aspect (named moves, explicit paths, and its on_aspect_mismatch refusal); the image is letter- or pillarboxed to that aspect first when fit="fit", and every window is slid inside the content box (see Still). burns renders integer rates only, so a fractional fps (29.97) is rendered at the next integer with the **same frame count**; each part restamps the frames at the edit’s rate (the move runs 0.1% slower; no frame is dropped or repeated). The default still_renderer of render(); any callable with this signature can replace it.

Return type:

Path

mixing.edit.probe_source(path)[source]¶

Displayed size, exact frame rate, frame count, sound format and stream offsets of path.

Uses ffprobe (its r_frame_rate is the exact rational; packets are counted, which reads but does not decode the file) when one is found beside ffmpeg or on PATH, else ffmpeg’s banner (rate snapped by as_rate(), frame count from the duration, no stream offsets). mixing.edit.timeline(segments, clips, *, fps, sample_rate, source_frames=None, join_fade=0.006)[source]¶

The frame-exact plan of an edit: frame and sample boundaries, sound and picture pieces. Pure: no file is read.

Parameters:

  • segments (Iterable) – Span / Gap.

  • clips (Mapping[Hashable, Union[Cam, Still]]) – clip id -> Cam / Still.

  • fps (Union[Fraction, int, float, str]) – the timeline rate (see as_rate()).

  • sample_rate (int) – the sound’s sample rate.

  • source_frames (Optional[int]) – the source’s frame count at fps: a span past it is refused, and dissolve handles past it hold the last frame (None: assume the source runs on).

  • join_fade (float) – fade (s) at each sound join that is not a continuous run.

Return type:

Timeline

...                 fps="30000/1001", sample_rate=48000)

((0, 30, 45), (0, 48048, 72072))
