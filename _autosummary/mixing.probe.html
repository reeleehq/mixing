mixing.probe

mixing.probe¶

One light media probe: ffprobe first, ffmpeg’s banner as the fallback.

What a file holds (its displayed size, exact frame rate, frame count, stream start times, rotation, duration, sound format), read by subprocess so that importing this module pulls no media library (no moviepy, opencv, numpy or PIL). mixing.edit and mixing.video.cutaways both read their sources through it.

>>> from mixing.probe import probe
>>> info = probe("talk.mp4")
>>> info.fps, info.frames, info.width, info.height
(Fraction(30000, 1001), 900, 1920, 1080)

Two methods, one result. probe() returns a frozen MediaProbe whose method says how it was read:

  • "ffprobe" (exact): the rate is r_frame_rate as a Fraction (30000/1001 stays exact), the frame count is

    the counted video packets (or the container’s nb_frames header), the video starts at its start_time and the sound at its first decoded frame (an opus stream’s first packet precedes it by its pre-skip), cover art (attached_pic) is not taken for the picture, the rotation comes from the display matrix (side data) or the rotate tag, and r_frame_rate is checked against avg_frame_rate (and the packet count against the duration) to detect a variable rate.

  • "banner" (approximate): when no ffprobe sits beside mixing.util.ffmpeg_exe() or on PATH (imageio-ffmpeg’s build ships

    none), the text ffmpeg -i prints is parsed by parse_banner(). The rates are the printed decimals (tbr as fps, fps as avg_fps) snapped by snap_rate(), the frame count is estimated from the container duration, both streams are assumed to start with the file, and a variable rate is seen only when the two printed rates disagree.

ffprobe= is the seam: the default finds one (find_ffprobe()), a path uses that binary, None forces the banner. A file that does not exist raises MediaNotFoundError; one ffmpeg cannot read raises ProbeError (both are ``ValueError``s).

mixing.probe.parse_banner(text)[source]¶

A MediaProbe from the text ffmpeg -i FILE prints (approximate).

The banner states the container duration, the first video stream’s coded size, its two rates (N tbr is ffmpeg’s guess at r_frame_rate and becomes fps; N fps is avg_frame_rate and becomes avg_fps; both snapped by snap_rate()), the display rotation and the first audio stream’s rate and layout. It has no per-stream start times (both streams are assumed to start with the file: video_start and audio_start are 0.0) and no packet count (frames is the container duration times fps), so a variable rate is detected only when the two printed rates disagree.

>>> found = parse_banner('''Duration: 00:00:10.50, start: 0.0
...   Stream #0:0: Video: h264, yuv420p, 1920x1080 [SAR 1:1], 29.97 fps
...   Stream #0:1: Audio: aac, 48000 Hz, stereo, fltp''')
>>> found.fps, found.frames, (found.width, found.height), found.channels
(Fraction(30000, 1001), 315, (1920, 1080), 2)

mixing.probe.probe(media, *, ffprobe='auto', count_packets=True)[source]¶

Probe media with ffprobe when there is one, else with ffmpeg’s banner.

Parameters:

  • media (Union[str, os.PathLike[str]]) – the file (or any location ffmpeg opens).

  • ffprobe (Optional[str]) – the ffprobe binary. AUTO_FFPROBE (default) finds one with find_ffprobe(); None forces the approximate banner (parse_banner()).

  • count_packets (bool) – have ffprobe count the video packets (reads, but does not decode, the whole file) for an exact frame count. False uses the container’s nb_frames header, which mkv lacks.

Raises:

  • MediaNotFoundError – media does not exist.

  • ProbeError – ffmpeg/ffprobe cannot read it, or the named ffprobe cannot be run.

  • ValueError – ffprobe="".

Return type:

MediaProbe

mixing.probe.snap_rate(fps)[source]¶

A float frame rate as the exact rate it stands for.

A rate near an integer or an NTSC rate (k * 1000 / 1001) is taken to mean it; anything else is approximated with a denominator of at most MAX_RATE_DENOMINATOR.

>>> snap_rate(29.97), snap_rate(25.0), snap_rate(23.976), snap_rate(12.5)
(Fraction(30000, 1001), Fraction(25, 1), Fraction(24000, 1001), Fraction(25, 2))
Return type:

Fraction
