mixing¶

Tools for video and audio editing.

mixing is organized into focused subpackages, each with a clear dependency footprint so you only pay for what you import:

  • mixing.audio — sliceable Audio, fades, crop, concat, overlay, alignment, segmentation (needs pydub).

  • mixing.video — sliceable Video, crop, loop, audio replace/normalize, Ken Burns, thumbnails, subtitles (needs moviepy / opencv).

  • mixing.transcript — speech-to-text (ElevenLabs Scribe, stdlib HTTP), filler removal, transcript formats (no heavy deps).

  • mixing.dubbing — text-to-speech re-voicing / translation from SRT.

  • mixing.srt — canonical SRT/timeline parsing & formatting (pure).

  • mixing.chapters — transcript → chapter markers (pure; LLM optional).

Lazy by design. Importing mixing (or a light submodule such as mixing.chapters / mixing.srt) does not import moviepy or opencv. The heavy backends load only when you first touch a name that needs them — e.g. mixing.Video or from mixing.video import replace_audio.

The top-level namespace is a curated, lazily-resolved facade over the subpackages; see __all__. For the full surface of a subsystem, import it directly (from mixing.audio import ...).

exception mixing.WindowTooWideForClip(*, clip_index, clip_duration_s, window_s, hop_s, max_window_s)[source]¶

Bases: MixingError, ValueError

An explicit analysis window leaves a clip no second, independent look.

Raised by mixing.audio.align_clips_to_reference() when the caller passes a window_s wider than max_window_s — the length above which the clip holds no second INDEPENDENT window, so the consensus vote has nothing to arbitrate and support comes back None.

Why an error and not a clamp or a silent single window: the caller asked for a windowed vote and would otherwise receive a single whole-clip correlation whose only signal is the ABSENCE of a support number — indistinguishable from a clip that is genuinely too short to support at any window (issue #43). Clamping would be worse still: an explicit window_s is the caller saying what a window means for their material, and silently measuring at a different one makes support incomparable across a set for a reason nothing reports.

It subclasses ValueError because it is an argument that cannot be honored, so existing except ValueError handlers around alignment keep working.

clip_index¶

Position of the offending clip in the clips sequence, or None when the caller did not identify one.

clip_duration_s¶

The clip’s duration in seconds.

window_s¶

The window that was asked for.

hop_s¶

The hop in force — the caller’s, or the one derived from window_s. Reported because it is part of the grid that was asked for; it is NOT part of the bound, which does not depend on it (see _max_supportable_window_s()).

max_window_s¶

The largest window that still leaves this clip a second, independent look. The bound is inclusive, so for any clip long enough to be worth aligning a retry at exactly this window measures — which is what makes it worth reporting. A degenerate clip of a sample or two has no such window at all; the value is floored at one sample there and is a lower bound rather than a promise.

mixing.detect_chapters(transcript, *, duration=None, min_chapters=3, max_chapters=8, min_spacing=10.0, target_count=None, segment_fn=None, model=None)[source]¶

Detect chapter markers from a transcript.

Parameters:

  • transcript – One of — a Scribe response dict (with "words"), a Scribe words list, SRT text, or a list of cue dicts/objects exposing start/end/text.

  • duration (float | None) – Media duration in seconds. Inferred from the transcript’s last timestamp when omitted; used to choose a sensible chapter count and to bound the final marker.

  • min_chapters (int) – Minimum chapters worth showing. If fewer survive the constraints, an empty list is returned.

  • max_chapters (int) – Upper bound on chapter count.

  • min_spacing (float) – Minimum seconds between consecutive chapters (players such as YouTube require >= 10s).

  • target_count (int | None) – Desired chapter count. When omitted, scales with duration (roughly one chapter per ~1.5 min, clamped to [min_chapters, max_chapters]).

  • segment_fn (Optional[Callable[[Sequence[dict], int], list[dict]]]) – Pluggable segmenter (segments, target_count) -> [{start, title}]. Defaults to default_segment_fn() (LLM-backed).

  • model (str | None) – Optional LLM model override for the default segmenter.

Return type:

list[Chapter]

Returns:

A list of Chapter, first at 0:00, spaced by at least min_spacing — or [] when the media can’t support min_chapters (e.g. it is too short).

mixing.has_ffmpeg()[source]¶

Return True if the ffmpeg binary is available on PATH.

Most real video work in mixing (concatenation, trim/pad, dimension normalization, audio replacement) shells out to ffmpeg via moviepy. Without it, some operations degrade silently — producing wrong-duration or lower-quality output instead of failing. Callers should check this at startup and refuse to run rather than emit broken media.

>>> isinstance(has_ffmpeg(), bool)
True
Return type:

bool

mixing.parse_vtt(vtt_text, *, clean=True)[source]¶

Parse WebVTT into cues; the counterpart of parse_srt().

Tolerates a missing hour field, cue settings, and NOTE/STYLE blocks. Cue identifiers are dropped: Cue.index is the cue’s 1-based position in the file. A cue with no text is kept (text=""). With clean (default) inline timestamp and <c> tags are stripped, entities unescaped and all whitespace, line breaks included, collapsed to single spaces; clean=False keeps each cue’s text as written (lines joined by newlines).

>>> [(c.start, c.end, c.text) for c in parse_vtt(
...     "WEBVTT\n\n01:02.500 --> 01:04.000\n<c>Hi</c> there")]
[(62.5, 64.0, 'Hi there')]
Return type:

list[Cue]

mixing.parse_vtt_words(vtt_text)[source]¶

Parse a WebVTT caption file into a word list shaped like Scribe’s.

Each entry is {"text", "start", "end", "type": "word"} (seconds), the same shape mixing.transcript.transcribe() returns under "words", so the result plugs into the word-level helpers (words_to_srt, mixing.audio.segmentation.text_before_segments(), …).

YouTube auto-captions carry per-word timings as inline <hh:mm:ss.mmm> tags; text before a line’s first tag takes the cue start (or, on a later line of the same cue, the latest timing seen), and the rolling duplicate lines (no inline timings) are ignored. A file with no inline timings falls back to one entry per cue (its whole text). A word ends where the next one starts (capped at its cue end). Tags are stripped and HTML entities unescaped.

>>> vtt = '''WEBVTT
...
... 00:00:12.240 --> 00:00:15.509 align:start position:0%
... Music<00:00:12.639><c> with</c><00:00:12.800><c> meaning</c>
...
... 00:00:15.509 --> 00:00:15.519 align:start position:0%
... Music with meaning
... '''
>>> [(w["text"], w["start"]) for w in parse_vtt_words(vtt)]
[('Music', 12.24), ('with', 12.639), ('meaning', 12.8)]
>>> parse_vtt_words("1\n00:01.000 --> 00:02.500\nRock &amp; roll\n\nNOTE hi\n")
[{'text': 'Rock & roll', 'start': 1.0, 'end': 2.5, 'type': 'word'}]
Return type:

list[dict]

mixing.seconds_to_srt_time(seconds)[source]¶

Format a time in seconds as an SRT timestamp HH:MM:SS,mmm.

Milliseconds are rounded (not truncated), with carry handled correctly, and negative inputs clamp to zero.

>>> seconds_to_srt_time(2592.187)
'00:43:12,187'
>>> seconds_to_srt_time(1.5)
'00:00:01,500'
>>> seconds_to_srt_time(-3)
'00:00:00,000'
Return type:

str

mixing.text_to_speech(text, voice_id, *, api_key=None, model_id='eleven_multilingual_v2', output_format='mp3_44100_128', voice_settings=None, language_code=None, timeout=600.0, cache=True, refresh=False, return_cache_status=False)[source]¶

Synthesize text to speech with ElevenLabs and return audio bytes.

Parameters:

  • text (str) – The text to speak.

  • voice_id (str) – ElevenLabs voice id (see list_voices()).

  • api_key (str | None) – API key. Falls back to env var ELEVENLABS_API_KEY (or ELEVEN_API_KEY).

  • model_id (str) – TTS model id. Defaults to eleven_multilingual_v2.

  • output_format (str) – ElevenLabs output_format query value, e.g. mp3_44100_128 (default), mp3_44100_192 (needs a paid tier), or pcm_44100.

  • voice_settings (Optional[Mapping[str, Any]]) – Override the default voice settings (stability, similarity_boost, style, use_speaker_boost). Merged over DFLT_VOICE_SETTINGS.

  • language_code (str | None) – Optional ISO-639-1 hint (e.g. "fr"). Only some models honor it; ignored by others.

  • timeout (float) – Total request timeout in seconds.

  • cache (Union[bool, str, Path]) – True (default) → use default_cache_dir(). False → no cache. A path → use that directory. The cache key is a SHA-256 of the text plus every parameter that affects the audio.

  • refresh (bool) – When True and cache is enabled, force a re-call and overwrite the cached entry.

  • return_cache_status (bool) – When True, return (audio, was_cached) instead of just audio. was_cached is True iff the bytes came from the on-disk cache (no ElevenLabs call = no spend), so a caller can attribute real cost. Default False keeps the bytes return.

Return type:

bytes | tuple[bytes, bool]

Returns:

Raw audio bytes in output_format (MP3 by default) — or, when return_cache_status is True, a (audio, was_cached) tuple.

Raises:

  • RuntimeError – No API key supplied and ELEVENLABS_API_KEY (or ELEVEN_API_KEY) unset.

  • HTTPError – Request failed (4xx/5xx).

mixing.transcribe(audio, *, api_key=None, model_id='scribe_v1', timestamps_granularity='word', tag_audio_events=True, diarize=False, language_code=None, extra_fields=None, timeout=600.0, cache=False, refresh=False)[source]¶

Transcribe audio with ElevenLabs Scribe.

Parameters:

  • audio (Union[str, Path, bytes]) – Path to an audio/video file, or raw bytes.

  • api_key (str | None) – API key. Falls back to env var ELEVENLABS_API_KEY (or ELEVEN_API_KEY).

  • model_id (str) – Scribe model id (currently scribe_v1).

  • timestamps_granularity (str) – "word" (default), "character", or "none".

  • tag_audio_events (bool) – Whether to surface (laughs) / (coughs) etc.

  • diarize (bool) – Speaker diarization on/off.

  • language_code (str | None) – Optional BCP-47 hint to skip language detection.

  • extra_fields (Optional[Mapping[str, str]]) – Additional multipart fields to send (forward compatible).

  • timeout (float) – Total request timeout in seconds.

  • cache (Union[bool, str, Path]) – False (default) → no cache. True → use default_cache_dir(). A path → use that directory. The cache key is the SHA-256 of the audio bytes plus all request parameters that affect the response.

  • refresh (bool) – When True and cache is enabled, force a re-call and overwrite the cached entry. Useful for invalidating stale entries when Scribe upgrades its model.

Return type:

dict[str, Any]

Returns:

The raw JSON response from ElevenLabs (a dict). When timestamps_granularity="word" (default), the response contains a "words" list where each entry has at minimum {"text", "start", "end", "type", "confidence"}. Non-word events (type != "word") include (laughs) etc. when tag_audio_events=True.

Raises:

  • RuntimeError – No API key supplied and ELEVENLABS_API_KEY (or ELEVEN_API_KEY) unset.

  • HTTPError – Request failed (4xx/5xx).

Translate the cue text of an SRT to target_language, keeping timings.
