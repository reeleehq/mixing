mixing.dubbing¶

Text-to-speech dubbing: re-voice or translate a video from its SRT.

The transcript side of mixing turns speech into SRT (ElevenLabs Scribe); this subpackage closes the loop — turning SRT back into speech with an ElevenLabs voice and muxing it over the video, optionally translating the SRT first to produce a foreign-language dub.

Building blocks:

  • text_to_speech() / synthesize_to_file() — ElevenLabs TTS.

  • list_voices() / find_voice() — discover account voices.

  • parse_srt() / dump_srt() / translate_srt() — SRT I/O and LLM-backed translation.

  • dub_video_from_srt() — the end-to-end pipeline.

The HTTP clients use stdlib only (no requests / elevenlabs SDK), so this adds no required deps. Needs ffmpeg on PATH and an ElevenLabs API key (env var ELEVENLABS_API_KEY (or ELEVEN_API_KEY) or explicit api_key=). Translation needs either the aix package (pip install 'mixing[llm]') or a custom translate_fn.

Lazy by design. Like the top-level mixing facade, this subpackage uses PEP 562 __getattr__ so that the TTS / SRT building blocks (text_to_speech(), list_voices(), parse_srt(), Cue, …) import with no moviepy dependency. Only dub_video_from_srt() — the end-to-end pipeline that muxes audio over a video — pulls moviepy, and only when it is first accessed.

Quick start:

>>> from mixing.dubbing import dub_video_from_srt, translate_srt
>>> dub_video_from_srt("promo.mp4", "promo.srt", voice_id="...", output="promo.en.mp4")
>>> fr_srt = translate_srt(open("promo.srt").read(), "French")

Search ElevenLabs’ public shared voice library (not just the account).

  • category (str | None) – e.g. "professional", "high_quality".

  • sort (str | None) – e.g. "trending".

  • page_size (int) – Max results.

  • extra_params – Any other query params the endpoint accepts.

mixing.dubbing.text_to_speech(text, voice_id, *, api_key=None, model_id='eleven_multilingual_v2', output_format='mp3_44100_128', voice_settings=None, language_code=None, timeout=600.0, cache=True, refresh=False, return_cache_status=False)[source]¶

Synthesize text to speech with ElevenLabs and return audio bytes.

Parameters:

  • text (str) – The text to speak.

  • voice_id (str) – ElevenLabs voice id (see list_voices()).

  • api_key (str | None) – API key. Falls back to env var ELEVENLABS_API_KEY (or ELEVEN_API_KEY).

  • model_id (str) – TTS model id. Defaults to eleven_multilingual_v2.

  • output_format (str) – ElevenLabs output_format query value, e.g. mp3_44100_128 (default), mp3_44100_192 (needs a paid tier), or pcm_44100.

  • voice_settings (Optional[Mapping[str, Any]]) – Override the default voice settings (stability, similarity_boost, style, use_speaker_boost). Merged over DFLT_VOICE_SETTINGS.

  • language_code (str | None) – Optional ISO-639-1 hint (e.g. "fr"). Only some models honor it; ignored by others.

  • timeout (float) – Total request timeout in seconds.

  • cache (Union[bool, str, Path]) – True (default) → use default_cache_dir(). False → no cache. A path → use that directory. The cache key is a SHA-256 of the text plus every parameter that affects the audio.

  • refresh (bool) – When True and cache is enabled, force a re-call and overwrite the cached entry.

  • return_cache_status (bool) – When True, return (audio, was_cached) instead of just audio. was_cached is True iff the bytes came from the on-disk cache (no ElevenLabs call = no spend), so a caller can attribute real cost. Default False keeps the bytes return.

Return type:

bytes | tuple[bytes, bool]

Returns:

Raw audio bytes in output_format (MP3 by default) — or, when return_cache_status is True, a (audio, was_cached) tuple.

Raises:

  • RuntimeError – No API key supplied and ELEVENLABS_API_KEY (or ELEVEN_API_KEY) unset.

  • HTTPError – Request failed (4xx/5xx).
