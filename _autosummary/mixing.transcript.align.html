mixing.transcript.align

mixing.transcript.align¶

Time authored words by a recogniser’s timed words of the same audio.

A script, a cue sheet or a line of dialogue says what was meant to be said; a transcriber (ElevenLabs Scribe, Whisper, …) says when each word it heard was said. align_words() walks the two in order (difflib.SequenceMatcher) and gives every authored token a time:

  • a token a heard word matches (same normalize_word() form) takes that word’s times;

  • a run heard differently (friend heard as fred) is spread over the misheard words’ span;

  • a run not heard at all is spread over the gap to the next anchor;

spreading in proportion to token length, so every token gets a plausible slot, and the result says how many were actually anchored (matched / total, coverage) and by which heard word (anchors).

Heard words are split into tokens the way the reference is (split=, default tokens_of()), so a heard "twenty-five" or "U.S." matches the script’s twenty, five / U, S: each piece takes its share of the word’s span, and anchors the word’s own index.

Stdlib only. Heard words may be (text, start, end) triples or mappings (Scribe’s text/start/end/type, or Whisper’s word); Scribe’s spacing and audio_event entries are skipped.

>>> heard = [("i", 0.0, 0.1), ("did", 0.1, 0.3), ("ask", 0.6, 0.9)]
>>> align_words(["I", "did", "NOT", "ask"], heard).words
[('I', 0.0, 0.1), ('did', 0.1, 0.3), ('NOT', 0.3, 0.6), ('ask', 0.6, 0.9)]

mixing.transcript.align.align_words(reference, heard, *, bounds=None, normalize=<function normalize_word>, split=<function tokens_of>)[source]¶

Time the reference tokens (what was meant to be said) by a recogniser’s heard words of the same audio.

bounds ((start, end) of the audio) time the ends when no anchor does; without it the first and last heard words do. normalize is the matching key (default normalize_word(): case-folded, punctuation dropped); pass your own for a language with elisions or a phonetic key. split cuts a heard word into tokens like the reference’s (default tokens_of(); None keeps each heard word whole). Heard words must come in time order (overlaps are fine); times must be finite.

The walk is difflib’s, roughly quadratic: about 0.2 s for 5,000 words, 4 s for 20,000; align long recordings by section.

>>> heard = [("i", 0.0, 0.1), ("did", 0.1, 0.3), ("ask", 0.6, 0.9)]
>>> aligned = align_words(["I", "did", "NOT", "ask"], heard)
>>> aligned.words
[('I', 0.0, 0.1), ('did', 0.1, 0.3), ('NOT', 0.3, 0.6), ('ask', 0.6, 0.9)]
>>> aligned.matched, aligned.total, aligned.anchors
(3, 4, {0: 0, 1: 1, 3: 2})

Scribe’s word list works as is (spacing and audio events are skipped, and anchors index the list as given):

>>> scribe = [{"text": "Hi", "start": 0.0, "end": 0.2, "type": "word"},
...           {"text": " ", "start": 0.2, "end": 0.3, "type": "spacing"},
...           {"text": "there.", "start": 0.3, "end": 0.6, "type": "word"}]
>>> align_words(["hi", "there"], scribe).anchors
{0: 0, 1: 2}
